2. Открыть https://supabase.com/dashboard/project/nwlthntpkmgrhmejhfqk/auth/url-configuration → Site URL = `https://f-gav.github.io/WreckLib/`.

4. Открыть https://f-gav.github.io/WreckLib/ и выполнить ручной вход по почте, затем проверить пробную кампанию, карточки, WebP и приглашения.

## Безопасность
Результат Supabase Security Advisor всё ещё отмечает намеренно открытые для authenticated RPC-функции `create_campaign` и `accept_invitation` с SECURITY DEFINER. Каждая проверяет auth.uid(), а приглашение также сверяет email. Перед публичным запуском проведём дополнительный аудит их действий. Проверки локальных пользователей в SQL — не замена браузерному E2E.

## Изоляция
Разработка ведётся исключительно в `f-gav/WreckLib` и отдельном Supabase WreckLib. WreckTrack и At your service! не изменяются. Исторические файлы Cloudflare не предназначены для запуска.

## 25.10.2026 — визуальная система и проверка публикации
- На текущей ветке WreckLib перенесены реальные четыре шрифта из `f-gav/WreckTrack/src/fonts`: Neuzeit Antiqua, Belarus, Ebbe, Old Town. Georgia оставлен по умолчанию. Файлы хранятся в WreckLib, WreckTrack не изменён.
- Сохранены четыре исходных цветовых акцента WreckTrack и соответствующие CSS-переменные.
- На телефонах работает явный переключатель `Разделы / Статья`; в десктопном режиме обе панели остаются видимыми.
- В GitHub Actions после деплоя проверяются HTTP 200 для HTML/JS/CSS и всех локальных шрифтов, что Google-провайдер включён, и что начало OAuth перенаправляет на Google. Отрицательные проверки отвергают невалидные гостевые ссылки и изображения.
- На дату аудита в `auth.identities` был email-провайдер, но не было подтверждённой Google-идентичности. Реальную авторизацию Google и сквозное приглашение двух аккаунтов нельзя признать протестированными без прохождения входа этими аккаунтами.
- Транзакционный тест приглашений подтверждает: точный адрес email (без учёта регистра) может принять приглашение, другой адрес отклоняется, `editor` получает только права редактора.
- Миграции и права в Supabase остаются отдельными от WreckTrack.
