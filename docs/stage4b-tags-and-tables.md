# WreckLib 4B — Markdown-таблицы, вложенные списки и теги

## Изменения
Таблицы с заголовком, выравниванием ячеек, вложенные маркированные и нумерованные списки до восьми уровней. Добавлены кнопки редактора и живой предпросмотр.

Теги: до 16 штук по 40 символов, ввод через запятые, точки с запятой и новые строки. Они сохраняются в public.entries.tags. Существующие карточки получают пустой массив тегов, сохраняя весь контент.

Фильтр по тегам и текстовый поиск могут работать одновременно. Нажатие на тег статьи открывает соответствующий фильтр. Цвета и шрифты WreckTrack сохранены.

## Безопасность
Теги читаются и записываются через существующие RLS-политики карточек. Новых общедоступных таблиц нет. Гость получает теги только опубликованных статей по токену и не может читать секреты. Поиск выполняется по уже разрешённым строкам. Markdown и теги экранируются перед отображением.

## Проверки
- Автоматические Node-тесты: таблицы, вложенные списки, XSS, теговые фильтры и UI.
- Транзакционный SQL: Мастер, Игрок+, Игрок, посторонний, гость, лимиты тегов; полная очистка данных откатом.
- GitHub CI на отдельной ветке до слияния.
- Live smoke опубликованного HTML, JS, CSS, fonts, tags.js и markdown.js после слияния.

## Ограничения
Это облегчённый Markdown, не полный CommonMark/GFM. Поиск локальный; для большого объёма потребуется серверный RLS-aware полнотекстовый индекс. Прямой браузерный E2E с реальными кампаниями не пройден, поскольку на момент тестирования кампаний в базе нет.
